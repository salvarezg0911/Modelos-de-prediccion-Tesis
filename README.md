# Proyecto Cassava: Propuesta para Reducir la Inseguridad Alimentaria

Este repositorio contiene el modelo y los análisis realizados en el marco del proyecto **Cassava**. 
Este proyecto busca desarrollar soluciones para **reducir la inseguridad alimentaria** mediante el uso de modelos predictivos aplicados a los cultivos de **yuca (cassava)**, un cultivo clave en la seguridad alimentaria en muchas regiones.

## Descripción

El propósito de este trabajo es generar modelos predictivos que puedan ayudar a la predicción de factores relevantes en la producción de yuca. El enfoque principal del proyecto es ayudar a los agricultores a mejorar su eficiencia en la producción y reducir el riesgo asociado con el cambio climático y otros factores externos.

### Objetivos del Proyecto:

- Crear un modelo predictivo para optimizar la producción de yuca.
- Evaluar las variables que impactan la producción de este cultivo.
- Analizar la relación entre factores climáticos y la producción agrícola de yuca.

## Estructura del Repositorio

- `Archivos IDEAM finales/`: Datos finales del Instituto de Hidrología, Meteorología y Estudios Ambientales de Colombia (IDEAM) utilizados en los análisis.
- `Resultados/`: Resultados y outputs generados durante la ejecución de los modelos.
- `*.xlsx`: Archivos de datos en formato Excel utilizados para las predicciones y análisis.
- `*.ipynb`: Jupyter Notebooks con el código para el análisis de los datos, entrenamiento de modelos y visualización de resultados.
- `README.md`: Este archivo con la descripción del proyecto.
