# Proyecto Cassava: Propuesta para Reducir la Inseguridad Alimentaria

Este repositorio contiene el modelo y los análisis realizados en el marco del p$

## Descripción

El propósito de este trabajo es generar modelos predictivos que puedan ayudar a$

### Objetivos del Proyecto:

- Crear un modelo predictivo para optimizar la producción de yuca.
- Evaluar las variables que impactan la producción de este cultivo.
- Analizar la relación entre factores climáticos y la producción agrícola de yu$

## Estructura del Repositorio

- `Archivos IDEAM finales/`: Datos finales del Instituto de Hidrología, Meteoro$
- `Resultados/`: Resultados y outputs generados durante la ejecución de los mod$
- `*.xlsx`: Archivos de datos en formato Excel utilizados para las predicciones$
